# 🤖 Jarvis AI Assistant (Python)

## 📌 Description

Jarvis is a simple AI voice assistant built using Python.
It can perform tasks like opening websites, playing music, and responding to voice commands.

This project demonstrates the use of speech recognition, text-to-speech, and automation in Python.

---

## 🚀 Features

* 🎤 Voice command recognition
* 🔊 Text-to-speech response
* 🌐 Open websites like Google, YouTube, etc.
* 🎵 Play music from a predefined library
* ⚡ Fast and interactive responses

---

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* Pyttsx3 (Text-to-Speech)
* PyAudio
* Webbrowser module

---

## ▶️ How to Use

1. Clone the repository
2. Install required libraries
3. Run the main Python file
4. Speak commands like:

   * "Open Google"
   * "Open YouTube"
   * "Play music"

---

## ⚙️ Installation

```bash
pip install speechrecognition pyttsx3 pyaudio
```

## ⚙️ How It Works

* The program listens to your voice using a microphone
* Converts speech to text using SpeechRecognition
* Processes the command
* Executes tasks (open website, play music, etc.)
* Responds using text-to-speech

---

## ⚠️ Common Issues

* PyAudio installation errors → install using compatible wheel file
* Microphone not working → check system permissions
* Speech not recognized → ensure clear audio input
